Wizytówka romanczuk.online — redesign

Date: 2026-10-02 · Branch: feat/card-redesign · Scope: / and /en, /og/card/[lang]

Co zostało zrobione

  • Wizytówka przepisana wg projektu Claude Design „Wizytówka – plansza”: profil (zdjęcie, imię, bio, akcje) po lewej, siatka bento po prawej (max 1240px); na telefonie jedna kolumna. Układ zawija się sam (flex-wrap + container queries), bez breakpointów.
  • Hierarchia: Vector Digital to jedyny ciemny kafelek z wypełnionym CTA; Portfolio i CV w ramce obok; korepetycje, gitara, homelab i blog jako lżejsze wpisy oddzielone linią.
  • Każdy kafelek ma etykietę odbiorcy („Dla firm”, „Dla rekruterów”, …).
  • Status „Wkrótce” nie zastępuje CTA: pulsująca kropka + „osobna strona Vector Digital” pod przyciskiem.
  • Jasny/ciemny tryb wg systemu; w ciemnym akcent rozjaśniony do #c9773a (kontrast AA).
  • Przełącznik PL | EN jako segmentowane linki (/, /en), z aria-current.
  • Usunięto niejasne „Masz link do swoich notatek?…”; Homelab linkuje do wpisu „Four boxes and a Pi”.
  • Nowy obrazek podglądu (Open Graph 1200×630) generowany statycznie pod /og/card/pl i /og/card/en; strony mają teraz og:image i twitter:card=summary_large_image (wcześniej brak podglądu przy udostępnianiu).
  • Font Instrument Sans (next/font, latin-ext) ładowany tylko na wizytówce; vCard przeniesiony do src/data/vcard.ts.

Jak przetestować

  1. cd landing-portfolio && npm run dev, otwórz http://localhost:3000/.
  2. Mobile (390px): przyciski Zadzwoń / Napisz / Zapisz kontakt widoczne bez przewijania; brak poziomego scrolla.
  3. Desktop (1440px): dwie kolumny; „Zapisz kontakt .vcf” w jednej linii; hover na kafelkach unosi je o 2px.
  4. Przełącz system na tryb ciemny → ciemne tło, akcent pomarańczowy, kafelek Vector Digital z miedzianą ramką.
  5. Kliknij EN → /en, treść po angielsku, lang="en"; PL wraca na /.
  6. Linki: Zadzwoń → tel:+48513602768; „Napisz w sprawie audytu” → mail z tematem; „Zobacz portfolio” → /portfolio; Strummy → nowa karta; „Jak to zbudowałem” → wpis o homelabie.
  7. Otwórz /og/card/pl i /og/card/en → PNG 1200×630. Po deployu: wklej link w LinkedIn Post Inspector / Messenger i sprawdź podgląd.
  8. Włącz „reduce motion” w systemie → brak animacji wejścia i pulsowania.
  9. Automaty: npx playwright test e2e/card.spec.ts (8/8 pass, w tym nowy test og:image), npm run lint, npx tsc --noEmit, npm run build — wszystkie przechodzą.
