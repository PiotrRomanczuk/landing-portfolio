SEO basics — romanczuk.online

Data: 2026-10-07 · Gałąź: feat/seo-basics

Co zostało zrobione

  • Jedna pisownia nazwiska w metadanych: „Piotr Romańczuk” (tytuły portfolio i CV, autor, alt obrazków OG/Twitter).
  • Dane strukturalne Person: name „Piotr Romańczuk” + alternateName „Piotr Romanczuk” (wersja bez polskich znaków, którą wpisują rekruterzy), jobTitle „Fullstack Engineer”.
  • Usunięty poziomy pasek przewijania na /portfolio (12px): .v5d-root { overflow-x: clip }. clip, nie hidden, żeby nie zepsuć position: sticky.

Jak przetestować

  1. npm run build && npx next start, otwórz /portfolio przy szerokości okna ok. 1200px.
  2. Brak poziomego paska; w konsoli document.documentElement.scrollWidth - document.documentElement.clientWidth zwraca 0.
  3. Najedź na wiersz projektu — tło podświetlenia nadal się pokazuje.
  4. Źródło strony: <title>Piotr Romańczuk | Fullstack Engineer</title>; w JSON-LD jest "alternateName":"Piotr Romanczuk".
  5. Sprawdź dane strukturalne w Rich Results Test po wdrożeniu.

Weryfikacja

  • tsc i eslint przechodzą. Lokalny build niemożliwy (brak miejsca na dysku) — build robi CI w PR.
  • Poprawka paska sprawdzona na produkcji przez wstrzyknięcie reguły CSS w Playwright: nadmiar szerokości 12px → 0, elementy sticky bez zmian.
