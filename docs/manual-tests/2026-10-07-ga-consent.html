Google Analytics 4 ze zgodą na cookies — romanczuk.online

Data: 2026-10-07 · Gałąź: feat/ga-consent · Zakres: landing-portfolio

Co zostało zrobione

  • GA4 przeniesione z gitarawarszawa.pl: Consent Mode v2, skrypt gtag.js ładuje się dopiero po „Akceptuję”.
  • Baner cookies: po polsku na /, po angielsku na pozostałych stronach. Przyciski są równorzędne.
  • Link „Ustawienia cookies” / „cookie settings” w stopce wizytówki (PL/EN) i portfolio otwiera baner ponownie, więc zgodę można wycofać.
  • Zdarzenia: contact_click, cv_download, vcard_download, outbound_click (z link_url).
  • Opcjonalnie Cloudflare Web Analytics (bez cookies), gdy ustawiony jest NEXT_PUBLIC_CF_BEACON_TOKEN.
  • Bez NEXT_PUBLIC_GA_ID nie ma ani banera, ani linku, ani GA — wdrożenie bez ID niczego nie zmienia.

Jak przetestować

  1. cd landing-portfolio && git checkout feat/ga-consent
  2. NEXT_PUBLIC_GA_ID=G-TESTTEST00 npm run build && npx next start -p 3124
  3. Otwórz http://localhost:3124/ w oknie prywatnym — baner po polsku w lewym dolnym rogu.
  4. „Odrzucam” → baner znika, w DevTools → Network brak googletagmanager.com, localStorage["cookie-consent"] = "denied".
  5. Stopka → „Ustawienia cookies” → baner wraca. „Akceptuję” → ładuje się gtag/js?id=G-TESTTEST00, w dataLayer są wpisy consent default (denied) + update (granted).
  6. /portfolio → baner po angielsku, w stopce „cookie settings”.
  7. Bez zmiennej: npm run build && npx next start → brak banera i linku.
  8. Po wdrożeniu z prawdziwym ID: GA4 → Raporty → Czas rzeczywisty, zaakceptuj cookies i kliknij link do CV.
